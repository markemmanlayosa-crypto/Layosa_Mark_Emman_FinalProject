# Student Record System

## Description
A CLI-based Python application that manages student records.

This project demonstrates:
- File handling
- Lists
- Dictionaries
- Loops
- Functions
- Algorithms
- Error handling

---

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Save Data to File
